# RPi.GPIO

RPi.GPIO-compatible Python GPIO support for Banana Pi Linux boards.

- [User and maintainer Wiki](https://github.com/BPI-SINOVOIP/RPi.GPIO/wiki)
- [Board support matrix](https://github.com/BPI-SINOVOIP/RPi.GPIO/wiki/Board-Support-Matrix)
- [Banana Pi IO porting plan](docs/banana-pi-io-porting-plan-20260601.md)

Support is specific to the exact board, carrier and revision. Confirm board
detection, voltage and the physical pin map before configuring any output.
