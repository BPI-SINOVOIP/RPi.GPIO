# RPi.GPIO Wiki source

This directory is the reviewable source for the GitHub Wiki at:

`https://github.com/BPI-SINOVOIP/RPi.GPIO/wiki`

Rules:

1. Edit and review these files in the main repository first.
2. Do not publish `README.md` to the Wiki repository.
3. Keep page filenames stable because GitHub Wiki links use the filename.
4. Push the rendered pages to `RPi.GPIO.wiki.git` only after links and Python examples pass review.
5. Product coverage, implementation status and hardware validation are separate claims; never promote one from another.

The companion BPI-WiringPi2 Wiki uses the same information architecture, but its examples and capability statements follow the C/CLI implementation.
